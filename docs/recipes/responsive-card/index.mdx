# Responsive card

Change the layout of a card based on available space rather than viewport width.
This allows the card to be placed in a narrow sidebar or a wide content area.

## Example

Move the **Container width** slider to adjust the width of the element
containing the card. As you cross the 400px threshold, the card will change to a
side-by-side layout with more generous spacing.

## Features

**Container width.** The wrapper establishes a container with
`containerType: "inline-size"`. The card can then query the nearest container’s
width to adjust its own layout accordingly.

**Coordinated layout.** The `@container (min-width: 400px)` condition changes
the flex direction, image width, and content padding all at the same time.
