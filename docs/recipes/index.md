# Recipes

These recipes demonstrate CSS Hooks patterns in complete,
editable examples. Although the examples use React, the
demonstrated hooks are compatible with other frameworks as
well.

1. [Button interaction states](./button/index.md): Combine
   hover, keyboard focus, active, and disabled states with
   accessible defaults.
2. [Responsive card](./container-card/index.md): Adapt a
   reusable card to its container with a container query.
3. [Light/dark mode with automatic inversion](./dark-theme/index.md)
   : Follow the system theme, support explicit overrides,
   and automatically alternate nested panel themes.
