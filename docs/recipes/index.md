# Recipes

These recipes demonstrate CSS Hooks patterns in complete,
editable examples. Although the examples use React, the
demonstrated hooks are compatible with other frameworks as
well.

1. [Button interaction states](./button-interaction-states/index.md):
   Combine hover, keyboard focus, active, and disabled
   states with accessible defaults.
2. [Custom placeholder](./custom-placeholder/index.md):
   Replace the browser's placeholder rendering with an
   accessible physical label that responds to the input's
   native state.
3. [Responsive card](./responsive-card/index.md): Adapt a
   reusable card to its container with a container query.
4. [Light/dark mode with automatic inversion](./lightdark-mode-with-automatic-inversion/index.md):
   Follow the system theme, support explicit overrides, and
   automatically alternate nested panel themes.
5. [Disclosure state](./disclosure-state/index.md): Style a
   disclosure and its descendants from the native open
   state.
