# Automatic light/dark inversion

Light and dark modes let an application adapt to a user's preferred appearance.
A panel may also need to adapt to its surrounding context by switching to the
opposite mode to create visual contrast.

This `ContrastPanel` component demonstrates that approach. The page inherits
your chosen theme for the site by default. Try selecting Light or Dark to
override it, and notice that the outer panel contrasts with the page while the
inner panel contrasts with the outer panel.

## Theme inheritance

The `"%dark"` hook carries the theme as inherited Boolean state. The
`enable("%dark")` and `disable("%dark")` functions set that state for an element
and its descendants, and the `on("%dark", …)` function applies style overrides
when the flag is enabled.

`ContrastPanel` does not expose a `theme` prop or consume React context. It does
not need to: an ancestor defines the initial state, and descendants inherit it
through CSS. See [Flags](../../flags/) for details.

## Inversion boundary

```typescript
const invertDark = mergeStyles(enable("%dark"), on("%dark", disable("%dark")));
```

An inversion boundary switches dark mode on or off at each nesting level. When
the boundary inherits an enabled dark-mode flag, it disables the flag for itself
and its descendants. Otherwise, it enables the flag for them.

Passing `invertDark` to `mergeStyles` adds the boundary to a style. Each
`ContrastPanel` applies it to contrast with its surrounding theme, so nested
panels automatically alternate between light and dark.
