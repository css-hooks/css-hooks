# Disclosure state

A disclosure is a control that shows or hides related content. The `<details>`
element provides this behavior natively: its `<summary>` element responds to
pointer and keyboard input, and the `:open` pseudo-class exposes its state to
CSS. Descendants can respond without copying the state into React.

Open and close a question with a pointer or keyboard. The border changes and the
chevron rotates when the `<details>` element opens.

## Native open state

The `&:open` hook activates for an open `<details>` element. The contextual
`:open &` hook activates for a descendant of an open element. The example uses
these hooks to style the container, chevron, and answer while the browser
remains the sole owner of the open state.

## Focus handling

`outline: "none"` removes the default outline from the `<summary>` element. The
`:focus-visible &` hook displays a replacement focus ring on the chevron, so
keyboard users retain a visible indicator. Browsers generally match
`:focus-visible` for keyboard focus but not for pointer focus.
