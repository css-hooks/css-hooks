# Recipes

These recipes show how to use CSS Hooks for common interface patterns, including
interaction states, responsive components, and inherited themes. Each recipe
combines an interactive React example with the hooks that style it. You can use
the same hooks with other frameworks.

If you are new to CSS Hooks, first learn about
[Applying styles](../applying-styles/). Recipes that share state through the
element tree build on [Flags](../flags/).
